# 🏟️ Smart Stadium GenAI

An AI-powered Smart Stadium Management System built using **Flask**, **Python**, and **MySQL**. The project provides intelligent stadium services including ticket booking, navigation, crowd monitoring, parking management, AI chatbot, emergency alerts, multilingual support, attendance prediction, sustainability monitoring, and real-time analytics.

# ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/Smart-Stadium-GenAI.git
```

```bash
cd Smart-Stadium-GenAI
```

---

### Create Virtual Environment

```bash
python -m venv venv
```

Windows

```bash
venv\Scripts\activate
```

Linux / Mac

```bash
source venv/bin/activate
```

---

### Install Dependencies

```bash
pip install -r requirements.txt
```

---

### Run Application

```bash
python app.py
```

or

```bash
flask run
```
